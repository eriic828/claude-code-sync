# draw.io 图表生成工具（Claude Code集成指南）
## 🔧 工具简介
这是AI驱动的draw.io/diagrams.net图表生成工具，可以直接在Claude Code中通过自然语言生成各种专业图表，无需手动拖拽，大幅提升工作效率。
## ✨ 核心功能
| 功能 | 说明 |
|------|------|
| 🎯 **20+图表类型** | 流程图、架构图、UML、ER图、时序图、思维导图、网络拓扑、甘特图等 |
| 🤖 **AI智能生成** | 自然语言描述需求，自动生成符合逻辑的图表 |
| 📤 **多格式导出** | 支持导出draw.io原生可编辑格式、PNG、SVG、PDF、Visio兼容格式 |
| 🎨 **多主题支持** | 浅色、深色、手绘、科技、商务、极简等6种主题风格 |
| 🔄 **无缝集成** | 生成的文件可以直接在draw.io桌面版、在线版、VS Code扩展中打开编辑 |
## 🚀 使用方法
在Claude Code对话中直接调用：
```
/drawio [图表需求] [可选参数]
```
### 快速模式（推荐）
直接描述需求，自动识别类型：
```
/drawio "AI微服务系统架构图，包含用户层、API网关、业务服务、数据存储层"
```
### 自定义模式
指定参数精细化控制：
```
/drawio "用户注册登录完整流程，包含验证码校验、密码加密、第三方登录" --类型 流程图 --主题 商务 --导出 all
```
## 📋 完整参数说明
| 参数 | 可选值 | 说明 |
|------|--------|------|
| `--类型` / `--type` | `流程图` `架构图` `UML` `ER图` `时序图` `思维导图` `网络拓扑` `甘特图` `用户旅程图` | 指定生成的图表类型，不指定会自动识别 |
| `--主题` / `--theme` | `浅色` `深色` `手绘` `科技` `商务` `极简` | 图表风格，默认浅色 |
| `--导出` / `--export` | `drawio` `png` `svg` `pdf` `all` | 导出格式，多格式用+连接，默认导出drawio+SVG预览 |
| `--参考` / `--reference` | 任意文本 | 参考素材、结构说明、已有逻辑、字段说明等 |

## 📥 导入draw.io教程
生成的.drawio文件可以直接导入所有版本的draw.io：
### 方法1：在线版/桌面版
1. 打开draw.io → 左上角菜单「文件」→「导入」
2. 选择生成的`.drawio`文件 → 点击「导入」
3. 即可二次编辑、调整样式、导出其他格式
### 方法2：VS Code扩展
1. 安装「Draw.io Integration」扩展
2. 直接在VS Code中打开生成的`.drawio`文件，即可编辑
## ✨ 调整指令
生成图表后可以直接用指令调整，无需重新生成：
| 指令 | 功能 |
|------|------|
| `/修改 调整布局，把支付模块移到右侧` | 修改图表结构、布局、内容 |
| `/换主题 手绘` | 更换图表主题风格 |
| `/导出格式 pdf` | 重新导出为PDF格式 |
| `/增加 优惠券抵扣流程` | 增加新的节点/流程/模块 |
| `/删除 第三方登录模块` | 删除指定节点/流程/模块 |
| `/调整布局 让层次更清晰` | 优化布局 |
## 🎯 最佳实践
1. **需求越具体越好**：说明清楚包含的模块、关联关系、流程步骤，生成的图表准确率越高
2. **先粗后细**：先生成大体结构，再用调整指令修改细节，比一次性说清楚所有细节效率更高
3. **复杂图表分层**：特别复杂的图表可以先生成核心模块，再逐步增加内容
4. **导出`all`格式**：需要多端使用的话，直接导出所有格式，方便不同场景使用
## ❓ 常见问题
### Q：生成的Mermaid代码可以直接用吗？
A：是的，返回的Mermaid代码可以直接复制到任何支持Mermaid的工具（Notion、Obsidian、Markdown编辑器）中使用，也可以直接导入draw.io。
### Q：可以导入Visio吗？
A：可以，draw.io支持导出为Visio兼容格式，或者生成.drawio文件后在draw.io中导出为Visio的.vsdx格式。
### Q：支持大尺寸架构图吗？
A：支持，生成的文件是矢量格式，支持任意大小的图表，也可以导出高清PNG用于打印或演示。
### Q：如何修改生成的图表？
A：有两种方式：1. 导入draw.io手动调整 2. 用调整指令让AI自动修改。

## 📁 文件保存路径
生成的文件默认保存在当前工作目录的`drawio-exports/`文件夹下：
```
./drawio-exports/
├── [名称].drawio    # drawio可编辑原文件
├── [名称].svg       # 矢量预览图
├── [名称].png       # 高清PNG图（如果指定导出）
└── [名称].pdf       # PDF文件（如果指定导出）
```
